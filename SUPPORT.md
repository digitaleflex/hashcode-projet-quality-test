# Support

## Avant de demander de l'aide

1. Consultez le `README.md`.
2. Lancez `npx hashcode-quality doctor` dans le projet concerné.
3. Vérifiez la documentation dans `docs/`.
4. Recherchez les Issues existantes.
5. Pour un bug reproductible, utilisez le modèle d'Issue prévu à cet effet.

## Questions et discussions

Utilisez les GitHub Discussions du projet lorsqu'elles sont activées pour les questions générales, idées et échanges qui ne constituent pas un bug confirmé.

## Bugs

Utilisez une Issue avec les informations de reproduction, l'environnement, la commande exécutée, le résultat attendu et le résultat observé.

## Sécurité

Pour les vulnérabilités, ne publiez pas de détails sensibles dans une Issue publique. Consultez `SECURITY.md`.
