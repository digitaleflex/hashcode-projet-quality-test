# Code of Conduct

## Notre engagement

Nous voulons une communauté technique ouverte, professionnelle et respectueuse. Toute personne qui contribue, maintient, documente, teste ou utilise le projet doit pouvoir participer sans harcèlement ni discrimination.

## Comportements attendus

- Communiquer avec respect et précision.
- Critiquer le code, les décisions et les propositions, pas les personnes.
- Accueillir les questions et les niveaux d'expérience différents.
- Donner des retours constructifs et orientés vers les faits.
- Respecter la confidentialité et ne pas publier d'informations privées.

## Comportements inacceptables

- Harcèlement, intimidation ou discrimination.
- Menaces, attaques personnelles ou propos dégradants.
- Publication de données personnelles sans autorisation.
- Spam, manipulation volontaire des discussions ou comportement perturbateur répété.
- Toute utilisation du projet pour faciliter une activité illégale ou dangereuse.

## Application

Les mainteneurs peuvent retirer, modifier ou fermer une contribution ou une discussion qui viole ce code. Les cas graves ou répétés peuvent entraîner une restriction de participation.

## Signalement

Pour un problème de comportement, contactez les mainteneurs via les canaux indiqués dans `SUPPORT.md`. Pour une vulnérabilité de sécurité, utilisez exclusivement la procédure de `SECURITY.md`.
